# Research AI Portfolio

面向研究所 AI 应用、知识工程与智能研发工具岗位的公开作品入口。这里仅链接可公开、可说明个人边界的材料；不包含任职单位内部代码、数据、文档或未获授权的团队资产。

## 可复现工程

### [CodeAtlas-C](https://github.com/g18042663173-a11y/codeatlas-c)

面向大型 C 工程代码理解的本地知识库：使用 Clang AST/USR 构建可信代码图谱，融合符号匹配、BM25、本地向量与调用图扩展，经 RRF 与特征重排组织上下文；无 A/B 证据时在模型前拒答。Agent 仅开放六类只读工具并限制调用预算，用知识快照钉住同一套 facts / index。

对外冻结评测：在公开 cJSON、lwIP 共 **20** 道固定代码检索开发题上，Recall@10 较 BM25 平均提升 **15** 个百分点（分库为 +10 / +20）；本地检索 P95 低于 **50 ms**；拒答 **100%**，certain 影响分析 F1 为 **1.0**。

该仓库是基于公开语料的个人可复现工程，不是华为官方产品，不含华为内部代码或数据。

### [Cross-Domain CTR](https://github.com/g18042663173-a11y/cross-domain-ctr)

跨域广告 CTR 预估实验框架：SENet / FM / DCN-M 特征交叉，信息流与广告双域兴趣 Attention，Symmetric InfoNCE 表征对齐。公开训练与评估代码；**不含**竞赛原始 CSV 与 checkpoint。

离线冻结口径：相较 Baseline，AUC **+2.18%**，GAUC **+1.49%**。

### [问题工单经验知识库](https://github.com/g18042663173-a11y/issue-ticket-kb)

面向 C 语言开发团队的问题沉淀与检索工作台：AI 只生成草稿，人工确认后才进入正式检索；实现中文检索、状态机、修订历史、批量恢复、数据出境守卫、MCP 只读/草稿工具和 Windows 桌面交付。隔离 PostgreSQL 16.15 上 174 项测试通过；28 条 synthetic 数据、34 条固定评测的 Recall@5 为 `1.0000`、MRR 为 `0.8978`、负例通过率为 `1.0000`。

仓库不包含真实工单、数据库、密钥、`.env` 或大型安装包。工程实现主要借助 Coding Agent；本人负责需求定义、方案取舍、结果验收与交付边界。

### [doc-agent](https://github.com/g18042663173-a11y/doc-agent)

企业文档生成 Agent：材料 → IR → 可编辑 Word/PPT。含 `toolkit/`（Skill + WPF + IR 门禁）与 `mvp/`（FastAPI + React 本地工作台）两套交付；默认 stub 模型，不依赖外部密钥。
